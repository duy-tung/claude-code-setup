# Claude Code Hooks

This directory contains hooks for Claude Code sessions.

## Hooks Overview

| Hook | Location | Description |
|------|----------|-------------|
| **Scout Block** | `scout-block.cjs` | Blocks heavy directories (node_modules, .git, etc.) |
| **Privacy Block** | `privacy-block.cjs` | Prevents access to sensitive files |
| **Workflow Artifact Gate** | `workflow-artifact-gate.cjs` | Opt-in validation for fix/cook review artifacts before finalize/ship actions |
| **Session Init** | `session-init.cjs` | Session startup initialization |
| **Dev Rules** | `dev-rules-reminder.cjs` | Development rules injection |

## Enablement vs Registration

The `hooks.<name>` flags in `.claude/.ck.json` (and the defaults in `ck-config-utils.cjs`) only **gate** a hook that is already wired to an event in `.claude/settings.json` — a `true` value does **not** register the hook. Some entry hooks ship enabled-by-default in that gate map but are intentionally NOT registered to any event in the default `settings.json` (e.g. `task-completed-handler`, `teammate-idle-handler`, `usage-context-awareness`, `team-context-inject`); they fire only if you add the matching event entry to `settings.json` yourself. Enabling them in `.ck.json` alone has no effect.

## Scout Block Hook

Cross-platform hook blocking heavy directories to improve Claude performance.

**Blocked Patterns** (baseline in `.claude/.ckignore`, optional override in `<project-root>/.claude/.ckignore`):
- `node_modules`, `__pycache__`, `.git`, `dist`, `build`

**Testing:**
```bash
echo '{"tool_input":{"command":"ls node_modules"}}' | node .claude/hooks/scout-block.cjs
```

## Workflow Artifact Gate

Validates structured review artifacts generated by `ck:fix` and `ck:cook`.
Manual use:

```bash
node .claude/hooks/workflow-artifact-gate.cjs --stage finalize --artifact-dir plans/example/reports/harness
```

Opt in through `.claude/.ck.json`:

```json
{
  "hooks": {
    "workflow-artifact-gate": true
  },
  "workflowArtifactGate": {
    "enabled": true,
    "softStages": ["finalize", "commit"],
    "hardStages": ["ship", "push", "pr", "deploy"],
    "highRiskAutoStop": true
  }
}
```

Then add hook commands to `.claude/settings.json`:

```json
{
  "hooks": {
    "UserPromptSubmit": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "node \".claude/hooks/workflow-artifact-gate.cjs\""
          }
        ]
      }
    ],
    "PreToolUse": [
      {
        "matcher": "Bash",
        "hooks": [
          {
            "type": "command",
            "command": "node \".claude/hooks/workflow-artifact-gate.cjs\""
          }
        ]
      }
    ]
  }
}
```

Emergency disable: set `CK_WORKFLOW_ARTIFACT_GATE_DISABLED=1` or set
`hooks.workflow-artifact-gate` to `false`.
